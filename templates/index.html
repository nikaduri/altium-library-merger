Git Merge Driver Integration

Altium Designer stores libraries as binary OLE compound files. When coworkers merge Git branches, Git's default behavior is to treat libraries as raw binaries, triggering conflicts that corrupt the file with Git conflict markers.

You can configure Git to automatically use this Altium Merge Driver with a single command:

python altium_merge_cli.py git-install

What this command does:

  1. Registers a custom Git merge driver in your repository config (merge.altiumlib.driver).
  2. Updates your .gitattributes to automatically route all *.SchLib and *.PcbLib merges through the merger.
  3. Whenever coworkers run git merge or git pull, unique additions from both coworkers are merged cleanly and conflicting parts are preserved without data loss!

Manual CLI Commands:

You can also diff and merge directly from your terminal or CI/CD pipelines:

# Compare two libraries: python altium_merge_cli.py diff CompanyLib_v1.SchLib CompanyLib_v2.SchLib # Merge two libraries: python altium_merge_cli.py merge LibA.SchLib LibB.SchLib -o Lib_Merged.SchLib --prefer-mine
